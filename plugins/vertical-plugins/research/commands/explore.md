# Explore Command

Navigate and understand code efficiently.

## Workflow

### Step 1: Parse Query

Determine what to find:
- Function/variable name
- File pattern
- Feature description

### Step 2: Search

Use `code-spelunker` skill to:
1. Grep for targets
2. Read relevant files
3. Trace data flow

### Step 3: Map

Build a code map showing:
- Entry points
- Key files
- Data flow
- Dependencies

### Step 4: Report

Output findings with file paths and line numbers.
