# Demo Command

Turn a PR or feature into a visible proof story and video deliverable.

## Workflow

### Step 1: Parse Arguments

Determine:
- PR reference or feature description
- Layout: side-by-side (comparison) or single (new feature)
- Showcase wrapping: yes/no
- Keystroke overlay: yes/no
- Effects tier: utilitarian | full | none

### Step 2: Plan

Design the demo script:
1. Launch and establish baseline
2. Exercise the feature
3. Show the disambiguating result
4. Clean exit

### Step 3: Load Skills

Use routing from `capture`, `compose`, `verify`:
- Target route: determine driver (terminal/browser)
- Stage route: capture + compose + verify
- Artifact route: showcase if polish needed

### Step 4: Capture

Record the interaction. For comparisons, capture both branches.

### Step 5: Compose

Assemble into final video with layout, labels, effects.

### Step 6: Verify

Check against original commitments.

### Step 7: Report

- File path, resolution, duration
- What each phase demonstrates
- Timestamps for key moments
