# Plan Epic Command

Break a high-level epic into actionable Linear issues with proper structure.

## Workflow

### Step 1: Parse Input

Determine:
- Epic description or Linear epic URL
- Target team/project in Linear
- Priority level (urgent, high, normal, low)
- Any specific assignees or labels needed

### Step 2: Decompose Epic

Break the epic into 3-7 issues:
- Each issue should be completable in 1-3 days
- Issues should have clear acceptance criteria
- Dependencies between issues should be noted

### Step 3: Create Linear Issues

For each issue:
1. Create in Linear via MCP
2. Set title, description, priority, labels
3. Link to parent epic
4. Assign to appropriate team member or leave unassigned

### Step 4: Report

Output:
- Epic summary
- List of created issues with URLs
- Suggested execution order
- Any blockers or dependencies
