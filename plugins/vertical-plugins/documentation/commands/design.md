# Design Command

Create visual presentations and slide decks.

## Workflow

### Step 1: Define Topic

Determine presentation purpose and audience.

### Step 2: Outline

Create structure:
1. Title slide
2. Problem/context
3. Solution/approach
4. Evidence/results
5. Next steps

### Step 3: Create

Use `visual-design` skill to generate slides with Slidev.

### Step 4: Export

Output as PPTX, PDF, or hostable HTML.
