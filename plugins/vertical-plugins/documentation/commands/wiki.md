# Wiki Command

Generate a wiki for a codebase.

## Workflow

### Step 1: Survey

Use `wiki` skill to read repository structure and key files.

### Step 2: Discover Topics

Find subsystems, features, and domains in the code.

### Step 3: Generate Pages

Create documentation for each Tier 1 and Tier 2 topic.

### Step 4: Link

Cross-reference related topics.

### Step 5: Output

Generate `wiki/` directory with interconnected markdown files.
