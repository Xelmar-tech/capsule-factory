# Frontend Design

Practical tactics for designing and building frontend interfaces.

## Start with Creative Vision

### Tone
What feeling should this convey?
- Professional and trustworthy
- Playful and fun
- Calm and minimal
- Energetic and bold

### Aesthetics
Collect references. What do you admire with similar purpose?

## Add Constraints

### Spacing Scale
```
4, 8, 12, 16, 24, 32, 48, 64, 96, 128
```

### Type Scale
```
12, 14, 16, 20, 24, 32, 40, 48
```

### Color Palette
- One primary color
- Neutrals: white, black, 3-4 grays
- Semantic: red (error), green (success)

### Layout Grid
12-column grid with consistent gutters.

## Design in the Browser

Advantages of designing in code:
- Real constraints (viewport, performance)
- Interactive from the start
- Easy to iterate

## Tactics

### Whitespace
Let elements breathe. Generous padding and margins.

### Typography
- Limit to 2-3 fonts
- Use weight and size for hierarchy
- Line height: 1.5 for body, 1.2 for headings

### Color
- Use color intentionally
- Don't use too many
- Ensure contrast for accessibility

### Components
- Start simple, add complexity only when needed
- Reuse patterns
- Document variants

## Anti-patterns

- **Designing in isolation**: Mockups that don't account for real data
- **Too many colors**: Visual noise
- **Inconsistent spacing**: Looks unpolished
- **Ignoring mobile**: Design for all viewports
