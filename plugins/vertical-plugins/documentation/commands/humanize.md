# Humanize Command

Remove AI-generated patterns from text.

## Workflow

### Step 1: Read Text

Get the text to humanize (inline or from file).

### Step 2: Scan

Use `human-writing` skill to identify:
- Inflated significance
- Superficial -ing analyses
- Promotional language
- Vague attributions
- AI vocabulary

### Step 3: Rewrite

Replace AI patterns with direct, human language.

### Step 4: Add Voice

Add opinions, rhythm, complexity acknowledgment.

### Step 5: Output

Return humanized text.
